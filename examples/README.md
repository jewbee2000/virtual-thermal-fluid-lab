# Executed evidence

Generated by the authoring environment from the pinned project dependencies. These traces are synthetic model outputs, not physical measurements.

- `verification-results.txt`: actual 20-test output.
- `scenario-results.txt` / `suite.json`: actual seven-scenario results.
- Selected subfolders include raw telemetry, numerical summaries and source/config manifests.
- `sensor_bias_ramp/plot.png`: true and measured level, requested and applied pump command, and physical inflow.

A passing `pump_stuck_on` scenario exposes the expected uncontained hazard. `sensor_stuck` and `pump_failed_off` are characterization runs, not evidence of a validated detector or guaranteed containment.

The source was unversioned during generation; source hashes and dirty status are recorded. Initialize Git when beginning your own work. Codex configuration TOML was syntax-checked and documentation-reviewed; no local Codex CLI was available to test spawning. GitHub CI was not remotely executed. Python 3.12.14, uv 0.12.19, NumPy 2.3.5, SciPy 1.17.0 and Matplotlib 3.10.8 were used.
